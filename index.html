Cenários de gasto

Passagem aérea

Valores de ida e volta até o Aeroporto Internacional dos Guararapes (REC), servidos pela API de cotações. Com 8 semanas ou mais de antecedência aplica-se a tarifa de referência; abaixo disso incide um acréscimo estimado de sazonalidade que chega a 80% na véspera.

Estadia

Hospedagem considera 5 pernoites na região de Boa Viagem. Alimentação e transporte interno consideram os 6 dias de estadia. O transporte interno é multiplicado pelo fator de deslocamento da sede escolhida.

Ingresso

Os lotes do ENEJ 27 ainda não foram divulgados, então o ingresso está fora da interface e do total. A constante TICKET no JS já está preparada para reativá-lo quando o valor sair.

Dados

As tarifas vem de loadDynamicData(), que consulta a API configurada em API_ENDPOINT e cai no payload simulado quando a API não responde. Reconfirme os valores próximo à data de compra.
